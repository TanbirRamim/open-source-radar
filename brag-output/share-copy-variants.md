## LinkedIn

Most "good first issue" lists are stale, and half the issues are already taken.

So I built Open Source Radar: a free site that lists open source issues you can actually start today.

Every issue on it is open, has no assignee and no linked pull request, and comes from a project that was active in the last two months. It is rebuilt every 12 hours by a GitHub Actions workflow.

What is on the radar right now:
- 3,571 open issues across 1,208 active projects
- 1,389 of them carry a beginner label
- filters by language, topic, label level and project rules
- AI policy, CLA and DCO requirements shown before you start
- a 9-chapter guide that covers the parts people skip: checking an issue is really free, handling CLAs and anti-spam bots, and what to do when your PR is ignored

It is MIT licensed and the whole pipeline is a single stdlib-only Python script, so you can read exactly how issues are selected.

Try it: tanbirramim.github.io/open-source-radar
Repo: github.com/TanbirRamim/open-source-radar

If you maintain a project that welcomes newcomers, open an issue on the repo and I will add it.
