# For maintainers: the "on the radar" badge

If your project is listed on Open Source Radar, you can show newcomers where to find your beginner issues. The badge links to the website, filtered to your repository.

[![On Open Source Radar](https://img.shields.io/badge/on-Open%20Source%20Radar-2ea44f)](https://tanbirramim.github.io/open-source-radar/?q=OWNER%2FREPO)

Copy this into your README or CONTRIBUTING, and replace `OWNER%2FREPO` with your repository (for example `astral-sh%2Fruff`):

```markdown
[![On Open Source Radar](https://img.shields.io/badge/on-Open%20Source%20Radar-2ea44f)](https://tanbirramim.github.io/open-source-radar/?q=OWNER%2FREPO)
```

## Is my project listed?

Search for it on the [website](https://tanbirramim.github.io/open-source-radar/) or in the [projects directory](../projects/README.md). A project shows up when it is active, has open issues with a beginner label (`good first issue`, `help wanted` and [common variants](../scripts/config.toml)), and those issues have no assignee and no linked pull request. See [how issues are selected](../README.md#how-issues-are-selected).

Not listed but you think it should be? [Open an issue](https://github.com/TanbirRamim/open-source-radar/issues/new). Listed and would rather not be? Ask the same way and it's removed on the next refresh.

## Help newcomers succeed

A few things that make the difference between a first PR and an abandoned one:

- Write the issue so someone new can start: what to change, where, and how to test it.
- Say how to claim it (comment, a bot, or "just open a PR").
- Reply within a few days, even if it's only "thanks, will look this week".
