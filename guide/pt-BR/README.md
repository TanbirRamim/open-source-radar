# O Guia de Contribuição Open Source

Um caminho prático de "quero contribuir" até "meu pull request foi aceito", escrito para quem está fazendo isso pela primeira vez e útil para todo mundo depois disso.

Leia em ordem na primeira vez. Cada capítulo termina com uma lista de verificação curta à qual você pode voltar depois.

[English version](../README.md) · Capítulos 4 a 10 traduzidos para o português; os capítulos 1 a 3 ainda estão em inglês.

| 2 | [Set up your tools](../02-setup.md) (English) | Git, a GitHub account, SSH keys, an editor, and the command-line basics you will actually use |
| 3 | [Choose a project](../03-choose-a-project.md) (English) | How to tell a healthy, welcoming project from one that will ignore you |
| 4 | [Encontre uma issue que você consegue concluir](04-find-an-issue.md) | Como ler as etiquetas, verificar se alguém já a reivindicou e estimar o tamanho do trabalho |
