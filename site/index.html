    Before you pick an issue

    1. Check it is still free. Open the issue and look for new comments, assignees or linked pull requests. This page refreshes every 12 hours.
    2. Read the project's rules. Look at its contributing guide, pull request template and any AI policy. Badges here are detected automatically and can be wrong.
    3. Reproduce before you fix. Confirm the problem on your machine, then write a test that fails before your change.
    4. Keep it small. Change only what the issue needs, run the project's checks, and explain what you changed in plain words.
