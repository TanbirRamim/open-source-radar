# Security policy

Open Source Radar is a static website and a data pipeline that reads public GitHub data. It stores no user data and runs no server.

## Reporting a vulnerability

If you find a security problem, for example a way to inject script into the website through issue titles or repository descriptions, or a problem in the GitHub Actions workflows, please report it privately through [GitHub security advisories](https://github.com/TanbirRamim/open-source-radar/security/advisories/new) instead of opening a public issue.

Please include steps to reproduce. You can expect a first response within a week.

## Supported versions

Only the current `main` branch and the live website are supported.
